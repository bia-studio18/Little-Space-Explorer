# Little Space Explorer 🚀

A fun educational mini-game for kids aged **1–5 years**.

Built with pure **HTML, CSS, and JavaScript**.

---

### Game Modes – 20 Levels Each

| Mode              | Levels | What kids learn          | Stars / Difficulty |
|-------------------|--------|--------------------------|--------------------|
| **Color Planets** | 1–20   | Colors                   | More planets at higher levels |
| **Count Stars**   | 1–20   | Numbers (1 → 20)         | Stars increase up to 20 |
| **Planet Match**  | 1–20   | Memory & Matching        | More pairs at higher levels |
| **Build Rocket**  | 1–20   | Colors & Creativity      | More colors unlock |

---

### How Unlocking Works

- Each mode has **20 levels**
- Get **3 correct answers** to advance to the next level
- Finish **Level 5** of a mode to unlock the next game mode
- Progress is saved in the browser

---

### Features

- 🔊 Space-style sounds (correct, wrong, level-up, launch)
- 🪐 More realistic looking planets (gradients + rings)
- ⭐ Stars gradually increase from 1 up to 20
- 🔓 Level unlock system with popup
- Big buttons – perfect for little hands
- Fully responsive

---

### How to Run

1. Download / clone
2. Open `index.html` in any browser

No installation needed!
